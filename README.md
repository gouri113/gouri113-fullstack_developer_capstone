# Project Name: Best Cars Dealership

**Repository Name:** `xr wvm-fullstack_developer_capstone`

## Project Description

The Best Cars Dealership project is a full-stack web application developed as part of the IBM Full Stack Software Developer Capstone Project.

The application allows users to explore car dealerships, view dealer information and customer reviews, register and log in, and submit reviews for dealerships.

## Technologies Used

- React.js
- Django
- Flask
- Node.js and Express.js
- MongoDB
- HTML, CSS and JavaScript
- Docker and Kubernetes
